FAQ

Questions

Which search API should I use?
Start with Web Search. Switch when the query calls for it:
  • Pulse Search when the query points to a known page and speed or cost matters most.
  • Web Search Premier when the results must contain the answer, like agent Q&A or a specific fact.
  • Image, Video, News, Business or Place Search when you want that type of result.
Does one API key work for everything?
Yes. One key covers every Octen API. Usage is billed per API.
What does the Search Plan include?
The Standard plan is $20 a month: unlimited Web Search with no overage, plus 1,000 Image Search. Other APIs stay pay as you go.
How fresh is the index?
New pages are searchable within 5 minutes of being published, continuously.
